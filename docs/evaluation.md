# MVP Evaluation

第一阶段验收：

## Tool Accuracy

该调用的 Tool 能正确调用。

## Parameter Accuracy

Symbol、时间、周期、分页等参数正确。

## Evidence Coverage

关键结论有证据。

## Data Integrity

正确处理：

- partial
- error
- source
- timestamp

## Reasoning Quality

不能把相关性直接写成因果。

## Reproducibility

相同输入数据下输出结构基本稳定。

## Safety

不能：

- 执行交易
- 伪造数据
- 隐瞒数据缺失

建议后续建立 Case 001 ~ Case 100，记录：

- Tool selection accuracy
- Parameter accuracy
- Data completeness
- Evidence coverage
- Unsupported claim rate
- Reasoning consistency
- Latency
- Token cost
